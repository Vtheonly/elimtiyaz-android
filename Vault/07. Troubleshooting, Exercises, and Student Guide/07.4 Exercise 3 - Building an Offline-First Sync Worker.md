# 07.4 Exercise 3 - Building an Offline-First Sync Worker

## 1. Problem Scenario

You are tasked with designing and implementing an **Offline-First Synchronization Worker** (`SyncWorker`) using Android WorkManager, Kotlin Coroutines, and Hilt dependency injection.

### System Requirements:
1. The worker runs periodically in the background when network connectivity is available.
2. It must execute a **two-phase synchronization pipeline**:
   - **Phase 1 (Push)**: Drain all pending offline mutations from `sync_queue` to Supabase.
   - **Phase 2 (Pull)**: Fetch updated delta records from Supabase and upsert them into local Room SQLite.
3. If an individual mutation fails due to a network glitch, it must be retried on the next cycle using exponential backoff without crashing the entire worker process.

## 2. Complete Architectural Implementation

```kotlin
package com.example.infrastructure.sync

import android.content.Context
import androidx.hilt.work.HiltWorker
import androidx.work.CoroutineWorker
import androidx.work.WorkerParameters
import com.example.core.Result
import dagger.assisted.Assisted
import dagger.assisted.AssistedInject
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext

@HiltWorker
class SyncWorker @AssistedInject constructor(
    @Assisted context: Context,
    @Assisted params: WorkerParameters,
    private val pullSyncRepository: PullSyncRepository,
    private val pushSyncRepository: PushSyncRepository,
    private val onlineDetector: OnlineDetector,
) : CoroutineWorker(context, params) {

    override suspend fun doWork(): androidx.work.ListenableWorker.Result = withContext(Dispatchers.IO) {
        // Step 1: Guard against offline execution
        if (!onlineDetector.isOnline.value) {
            return@withContext androidx.work.ListenableWorker.Result.retry()
        }

        try {
            // Step 2: Phase 1 - Push outgoing offline mutations
            val pushResult = pushSyncRepository.drainPendingQueue()
            if (pushResult is Result.Err) {
                android.util.Log.w("SyncWorker", "Push queue drain partial error: ${pushResult.error.message}")
            }

            // Step 3: Phase 2 - Pull remote deltas into Room cache
            val pullResult = pullSyncRepository.pullAll()
            if (pullResult is Result.Err) {
                android.util.Log.w("SyncWorker", "Pull sync delta failed: ${pullResult.error.message}")
                return@withContext androidx.work.ListenableWorker.Result.retry()
            }

            android.util.Log.i("SyncWorker", "Sync completed successfully.")
            androidx.work.ListenableWorker.Result.success()
        } catch (e: Exception) {
            android.util.Log.e("SyncWorker", "Unexpected sync worker exception", e)
            androidx.work.ListenableWorker.Result.retry()
        }
    }
}
```

## 3. Important Tips and Implementation Reminders

> [!TIP]
> **Tip: Use `@HiltWorker` and `@AssistedInject`.**
> Android `Worker` instances are instantiated by the OS WorkManager runtime. To inject Hilt dependencies (`PullSyncRepository`, `DatabaseSeeder`) into a Worker, always use `@HiltWorker` and `@AssistedInject` with `@Assisted` context and params, and configure `HiltWorkerFactory` in `ElImtiyazApplication`.

> [!CAUTION]
> **Trap: Blocking the Coroutine Dispatcher.**
> Never run network I/O or Room database queries on `Dispatchers.Main`. Always wrap worker execution in `withContext(Dispatchers.IO)`.
